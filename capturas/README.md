# capturas/

Capturas de pantalla de los 16 proyectos del portfolio, agrupadas por proyecto.

- **Ronda**: 2026-08-31
- **Cómo se hicieron**: automatizado — Playwright para web, CDP sobre los
  binarios Tauri (Lil PDF / GYMORA / CVdeador), `expo start --web` para las
  apps React Native, renders headless para PDFs y planillas. Los backends
  dados de baja se cubrieron con mock data local realista (bypass de login,
  datos ficticios pero plausibles).
- **Estado detallado por proyecto**: ver [`_ESTADO.md`](_ESTADO.md).
- **Pendientes y notas para el portfolio**: ver [`../ToDo.md`](../ToDo.md).
